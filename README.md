# ⏳ Time Travel Timeline

## 📌 Project Overview

**Time Travel Timeline** is a web application that allows users to explore historical events from any given year. By entering a year (e.g., 1990, 2005), users can view a timeline of significant events that occurred during that time — creating an interactive “travel back in time” experience.

---

## 🎯 Features

* 🔍 **Search by Year**
  Enter a specific year to view historical events.

* 📜 **Historical Events Display**
  Fetch and display real-world historical events using a public API.

* 🔎 **Search Within Events**
  Filter events based on keywords.

* 🔃 **Sorting**
  Sort events in ascending or descending order by year.

* 🎨 **Timeline UI**
  Events are displayed in a clean, vertical timeline format.

* 🌙 **Dark Mode / Light Mode** *(optional)*
  Toggle between themes for better user experience.

* ❤️ **Favorites (Local Storage)** *(optional)*
  Save important or interesting events.

---

## 🌐 API Used

* **MuffinLabs History API**
  Provides historical events based on date.
  Example Endpoint:
  `https://history.muffinlabs.com/date`

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* Array Higher-Order Functions (map, filter, sort)

---

## ⚙️ How It Works

1. User enters a year.
2. The app fetches historical event data from the API.
3. JavaScript filters events based on the entered year.
4. Events are dynamically displayed in a timeline format.
