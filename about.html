About This Project

The History Timeline Web App is a web-based application that allows users to explore historical events by entering a specific year. It fetches real-time data from the Wikipedia API and displays it in a visually appealing timeline format.


🎯 Purpose

The main goal of this project is to demonstrate practical implementation of JavaScript concepts such as API integration, DOM manipulation, and dynamic rendering.


🚀 Features

  • Search historical events by year
  • Sort events alphabetically
  • Save favorite events
  • Dark/Light theme toggle
  • Optimized search using debouncing

🛠 Technologies Used

  • HTML, CSS, JavaScript
  • Wikipedia API
  • LocalStorage

👨‍💻 Developer

This project was developed as part of learning front-end web development and building real-world JavaScript applications.
